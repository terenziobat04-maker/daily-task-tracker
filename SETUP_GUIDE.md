# Daily Task Tracker Setup Guide

## Prerequisites
- **Node.js** and **npm** installed on your machine.
- Basic understanding of JavaScript.

## Step 1: Clone the Repository
Run the following command in your terminal to clone the repository:
```bash
git clone https://github.com/terenziobat04-maker/daily-task-tracker.git
```

## Step 2: Navigate to the Project Directory
Change to the project directory:
```bash
cd daily-task-tracker
```

## Step 3: Install Dependencies
Install the required dependencies using npm:
```bash
npm install
```

## Step 4: Run the Application
Start the application with the following command:
```bash
npm start
```

## Troubleshooting
If you encounter any issues, make sure all prerequisites are correctly installed and dependencies are up to date.
