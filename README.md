# Daily Task Tracker

## Project Overview
The Daily Task Tracker is a simple application designed to help users manage their daily tasks efficiently. It allows users to create, update, delete, and track their tasks over time.

## Features
- Create new tasks
- Update existing tasks
- Delete tasks
- View task history
- Mark tasks as completed

## Technologies Used
- JavaScript
- HTML
- CSS
- Node.js
- Express
- MongoDB

## Installation
To install and set up the Daily Task Tracker:
1. Clone the repository:
   ```bash
   git clone https://github.com/terenziobat04-maker/daily-task-tracker.git
   ```
2. Navigate into the project directory:
   ```bash
   cd daily-task-tracker
   ```
3. Install the required packages:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm start
   ```

## Usage
1. Open your web browser and navigate to `http://localhost:3000`
2. Use the interface to add, update, and manage your tasks.
